# Job Portal App

A full-stack web application built using Java and Spring Boot that allows job seekers to search and apply for jobs, and employers to post and manage job listings.

## 🛠️ Tech Stack

- **Backend:** Java, Spring Boot, Spring MVC
- **Frontend:** Thymeleaf, HTML, CSS, Bootstrap
- **Database:** MySQL
- **Build Tool:** Maven

## ✨ Features

- User registration and login (Job Seekers and Employers)
- Employer dashboard to post, update, and delete job listings
- Job seeker dashboard to view and apply for jobs
- Admin panel for managing users and jobs (if applicable)
- Responsive UI with Thymeleaf templates

## ⚙️ Setup Instructions

### Prerequisites
